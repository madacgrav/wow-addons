# Changelog — Profession Planner

All notable changes to this addon. Versions match `## Version` in `ProfessionPlanner.toc`; each version is published as a `pp-vX.Y.Z` GitHub release.

## [0.2.1] — 2026-10-20

### Added
- **Crafting-station requirements.** A plan step whose recipe needs a station shows it, for example `needs Loom` or `needs Spinning Wheel`. Recipes cached by older versions get their station data filled in on the next scan.

## [0.2.0] — 2026-10-20

Forever seed data, auction and vendor prices, and recipes you haven't learned yet.

### Added
- **Seed data from Forever game data** (build 1.60.1.70450, generated by `tools/gen_seed.py`). It covers color thresholds, reagents, the skill each pattern needs, and which pattern items teach each recipe. The panel can plan before you have seen a recipe change color yourself. Thresholds you observe in game still take priority over the seed.
- **Auctionator prices.** If Auctionator is installed, its last-seen buyout is used, and the panel refreshes when Auctionator's database updates.
- **Price sources.** Each reagent uses the cheapest of the vendor price and the AH price. A seed base price (`est.`) is used only for items a vendor is known to sell. The shopping list labels every price `vendor`, `AH` or `est.`.
- **QuestieDB vendors.** If QuestieDB is installed, the shopping list names a vendor for each reagent, filtered to your faction. A vendor in your current zone is preferred.
- **Planning recipes you haven't learned.** Once your skill reaches a pattern's requirement and the pattern has a price, the recipe can be planned. A "Learn: <pattern>" step comes before the craft step and shows where to buy the pattern. The pattern's cost is spread across the skill points it earns when ranking options.
- **Toggle tab.** A book icon on the profession window's side tab column shows and hides the panel. The panel now starts closed, and your choice is remembered.
- **Click to craft.** Click a plan step to select its recipe in the profession window with the craft count filled in. Shift-click crafts it right away.
- **`/pp probe` improvements.** It covers unlearned recipes, Auctionator and QuestieDB, catches API errors, and saves the full output to `ProfessionPlannerDB.lastProbe`.

### Changed
- The planner panel is wider, so recipe and vendor text fits.

### Removed
- Planned "route hints" from Classic leveling guides were dropped before release. Forever reworked the professions (renamed recipes, Forever-only recipes, moved thresholds), so those routes don't apply, and the live planner already routes from Forever data.

## [0.1.0] — 2026-10-20

First release.

### Added
- **Recipe scan.** Each time you open the window for a supported profession (Tailoring, Enchanting, Leatherworking or Alchemy), its recipes, reagents and difficulty colors are read and cached per character.
- **Docked planner panel.** A panel attached to the right of the profession window.
- **Planner.** Up to 3 steps toward your next skill bracket (75 / 150 / 225 / 300, capped by your current max). Each step picks the cheapest recipe per expected skill point. Orange and yellow recipes are preferred; green ones are used only when nothing else is left.
- **Inventory awareness.** Reagents in your bags, reagent bag and bank count as free. The bank is cached each time you open it.
- **Vendor price capture.** Opening any merchant records its prices for future plans.
- **Shopping list.** For every reagent the plan needs: have/need, how many to buy, and the unit price.
- **Threshold learning.** When a recipe changes color as you level, the skill where it happened is saved. Grey thresholds come from the game's `maxTrivialLevel`. Plans become more exact the more you craft.
- **`/pp probe`** prints API diagnostics. **CI** runs the tests and packages a release zip.

### Fixed
- The panel overlapped the profession window's side tabs.
- Recipes from a previously opened profession could leak into the current one.
- Empty plans, and the panel sometimes not appearing.
- Long row text is truncated instead of wrapping into the next row.
