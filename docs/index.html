WoW Forever Addons

Small, focused addons for the WoW Forever client (Interface 16001). Each addon lives in its own folder of the wow-addons repo, has its own README and changelog, and is released as a zip on GitHub every time its version changes.

Installing an addon

  1. Pick an addon below and click Download to get its .zip.
  2. Close the game, or plan to restart it.
  3. Open your World of Warcraft folder (default C:\Program Files (x86)\World of Warcraft\) and go to _forever_\Interface\AddOns\. Create the AddOns folder if it is missing.
  4. Extract the zip there. The addon folder (for example TackleBox) must sit directly inside AddOns, not inside another folder: _forever_\Interface\AddOns\TackleBox\TackleBox.toc.
  5. Start the game. On character select, click AddOns and make sure the addon is ticked.

Updating: delete the old addon folder, extract the new zip the same way, then restart or /reload. Your settings are kept (they live in WTF\, not the addon folder). Addons with key bindings (Warlock Combat Kit, BusinessCard) need a full restart the first time.

Removing: delete the addon folder from AddOns.
