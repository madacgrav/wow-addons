# Task

The Warlock Utility Kit "Preferred pet" option (settings dropdown and `/wuk pet <name>`) only offers Imp, Voidwalker, Succubus and Felhunter, so warlocks who have other demons (e.g. Felguard, Infernal/Doomguard if Forever exposes them as pets) cannot pick them for the strip's pet button. Goal: make the preferred-pet choice cover every summonable demon type available on WoW Forever, with the pet button, known-spell detection and "pet is out" check all working for the added demons.
