# Task

Survey the fishing addons that exist (or are announced) for WoW Forever on CurseForge, Wago, GitHub and other sites, and identify their gaps: missing features, things Classic-era fishing addons did that Forever ones don't, and features implemented poorly or broken on Forever's Mainline-based client. The output is a gap analysis captured as a GitHub issue in this repo, to pursue later as a possible new addon (no code now).
