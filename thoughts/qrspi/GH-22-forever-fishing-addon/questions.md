# Research Questions

## Context
Focus on the two existing addons in this repo (`ProfessionPlanner/`, `WarlockUtilityKit/`), their tests and packaging workflows under `.github/workflows/`, and the prior survey at `thoughts/qrspi/2026-10-21-forever-fishing-addon-gaps/research.md`. The client is WoW Forever (TOC `## Interface: 16001`, build 1.60.1), a Classic-content game on a Mainline-based client. Web sources (wago.tools DB2 tables, warcraft.wiki.gg, Forever guides) may be used where the repo has no answer.

## Questions
1. Trace how an addon in this repo goes from load to visible UI: TOC fields and file order, the Core/Logic split, `ADDON_LOADED`/`PLAYER_LOGIN` handling, SavedVariables defaults, event dispatch, and slash commands. How do the `tests/run.lua` harnesses load code without WoW APIs, and how do the packaging workflows test, zip and release each addon?
2. How do the existing addons read player state — buffs/auras (`C_UnitAuras`), profession and skill-line ranks, bag/bank item counts, current zone/subzone — and refresh it on events? Which of these calls are known to work on Forever, and which returned unexpected or secret values in past probe results (`probe-results.md` files)?
3. How do the existing addons construct UI: standalone frames, rows/lists, minimap button, settings panel, secure action buttons, combat-lockdown handling (`PLAYER_REGEN_ENABLED` deferral), and Edit Mode/dock positioning? What is reused between the two addons and what is duplicated?
4. What does the prior survey record about Forever fishing mechanics: Campsite Fishing Rack / Fishing Hut buffs and unlock skills, Uncommon/Rare/Unique fish tiers and the Chef's Knife, Legacy profession talents (Luremaster, Working Overtime, Dedicated Study), the Stranglethorn fishing tournament schedule and coin rewards, Artisan quest fish, and water-walking items? For each, which facts have IDs and sources, and which are marked unverified?
5. Which client APIs and events on Mainline 12.x / Forever expose fishing-related state: fishing skill rank, fishing channel and loot (`IsFishingLoot`, `LOOT_READY`, `GetLootSlotInfo`), aura spell IDs for buffs, server/realm time for scheduled events, and account-wide or Legacy progression data? Where are restrictions (secret values, protected functions) documented?
6. How is static game data produced for this repo (`ProfessionPlanner/tools/gen_seed.py` to `Data.lua`)? Which wago.tools DB2 tables hold fish items and their quality, fishing-related quests, spells/auras, and zone fishing data, and what fields and build versions are available for Forever?
