# Task

Build a third addon in this repo for WoW Forever fishing, per GitHub issue madacgrav/wow-addons#22. It targets Forever-only fishing content that existing fishing addons leave untouched (Campsite Fishing Rack/Hut buffs, Uncommon/Rare/Unique fish and the Chef's Knife, Legacy fishing talents, the Stranglethorn tournament, quest fish, water-walking reminders) and runs alongside a casting addon such as BetterFishing rather than replacing it. One-key casting and anything that reacts to a bite on the player's behalf are non-goals for v1.
