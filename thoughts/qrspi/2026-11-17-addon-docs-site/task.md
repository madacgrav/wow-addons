# Task

Build a static website, hosted on GitHub Pages from this repo (madacgrav/wow-addons), that explains what the repo is and its purpose, walks a player through installing an addon into the WoW Forever client, and presents each addon (ProfessionPlanner, TackleBox, WarlockCombatKit, WarlockUtilityKit, BusinessCard) in a tabbed view with its description, how it works, slash commands, and other details. Each addon's tab also links to download that addon's latest release and shows its changelog.

Going forward, the site must be kept current: every time an addon is added or updated (new version/release), its page content should be updated as part of that change.
